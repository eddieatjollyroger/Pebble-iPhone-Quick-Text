# Quick Text Setup_

iPhone setup (one time)
  1. Update to iOS 27. Allow notifications for the Home Assistant app.
  2. Open Shortcuts, then Automation, then add a new automation and choose Notification.
  3. App: Home Assistant. Filter: title contains your trigger word (default PEBBLE_TEXT).
  4. Set it to run immediately, not "Ask Before Running".
  5. Add these actions: Split Text on the notification's message with the custom separator ||; Get Item from List (first item) as the recipient; Get Item from List (last item) as the text; Send Message with that text to that recipient.
  6. Send yourself a test from the watch.

Contacts below are phone numbers or Apple ID emails. If it doesn't fire, the Home Assistant app's notifications may need to be set to show on the Lock Screen or Notification Center.

$ home assistant

Found automatically if you have one phone with the Home Assistant app.

The iPhone automation looks for this in the notification title.

$ contacts (up to 8)

"Number or email" is where the text goes: a phone number like +351912345678, or the Apple ID email for iMessage.

$ messages (up to 12)

The watch can't show emoji, so it hides them in its list, but they're still sent in the text. You can also dictate a message on the watch.

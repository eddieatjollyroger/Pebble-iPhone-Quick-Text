# Quick Text Setup_

iPhone setup (one time)

Quick way: install the ready-made shortcut, turn its automation on, and skip the steps below. If tapping it doesn't open Shortcuts, long-press the link and open it in Safari.

  1. Update to iOS 27. Allow notifications for the Home Assistant app.
  2. Open Shortcuts, then Automation, add a new automation and choose Notification. App: Home Assistant. Filter: title contains your trigger word (default PEBBLE_TEXT). Set it to run immediately.
  3. Add Split Text on the notification's message, with the custom separator ||. Then three Get Item from List actions: item 1 is the app, item 2 is the recipient, item 3 is the text.
  4. Add an If action: if the app is whatsapp, add WhatsApp's Send Message with the text to the recipient. Under Otherwise, add the Messages Send Message.
  5. Only add the apps you use. Anything else goes through Messages.
  6. Send yourself a test from the watch.

If an app's Send Message action won't take a number as the recipient, use the contact's name as saved in your iPhone's Contacts. Contacts below choose which app they go through.

Reply to the last message (optional)

Quick way: install the ready-made reply shortcut and turn its automation on. You still need to create the two Home Assistant helpers (the first step below). If tapping doesn't open Shortcuts, long-press the link and open it in Safari.

Adds a "reply" row at the top of the contact list with the last text your iPhone received. Works for any app the automation below can see, and the reply goes back through the same app.

  1. In Home Assistant, go to Settings, Devices & services, Helpers, and create two Text helpers named pebble_last_from and pebble_last_text. Set the maximum length of both to 255.
  2. On the iPhone, add one more Notification automation in Shortcuts, set to run immediately. Choose Messages, and WhatsApp too if it lets you pick several apps. Leave the title filter empty.
  3. Add a Text action containing the notification's app name, then ||, then the notification's title (the sender). It reads like WhatsApp||Anna.
  4. Add two Call Service actions from the Home Assistant app. Service input_text.set_value, with entity_id = input_text.pebble_last_from and value = that text. Then the same for input_text.pebble_last_text with value = the notification's message.
  5. Open the app on the watch after a message arrives. The reply row shows the sender, and the reply goes back through the app the message came in on.

Messages older than three hours are ignored. Notifications must be allowed to show previews for the automation to read them.

$ home assistant

Found automatically if you have one phone with the Home Assistant app.

The iPhone automation looks for this in the notification title.

$ contacts (up to 8)

"Number or email" is where the text goes: a phone number like +351912345678, or the Apple ID email for iMessage.

$ messages (up to 12)

The watch can't show emoji, so it hides them in its list, but they're still sent in the text. You can also dictate a message on the watch.
